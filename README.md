# Unemployment Analysis with Python (Covid-19 Impact)

This project analyzes the unemployment rate in India during the year 2020, focusing on the heavy socio-economic impact of the COVID-19 pandemic and lockdowns.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **IDE:** Spyder
- **Libraries:** Pandas, NumPy, Matplotlib

## 📊 Key Insights
- A massive spike (Peak) in the unemployment rate is clearly observed during April and May 2020, perfectly aligning with the strict nationwide lockdown.
- The project visualizes trends using Line Plots for months and Bar Plots for regional comparisons.
